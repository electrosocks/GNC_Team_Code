# GNC Team Repository

This repository contains development work for the Guidance, Navigation, and Control team.

## Repository Structure

### maneuver_planner
Development of the autonomous spacecraft maneuver-planning architecture.

### team_projects
Individual and subteam development work.

### common
Shared utilities, models, and reusable code.

### docs
Project documentation, team structure, and technical resources.

### presentations
Team presentations and briefings.

### archive
Older or inactive work retained for reference.

## Team Workflow

1. Work inside your assigned folder or project area.
2. Use descriptive commit messages.
3. Avoid modifying another team member's work without coordinating.
4. Reusable code should eventually be moved into the appropriate shared folder.
5. Major changes should be reviewed before merging into the main branch.
